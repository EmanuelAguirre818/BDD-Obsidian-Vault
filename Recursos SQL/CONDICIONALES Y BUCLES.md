- Ejecutan piezas de codigo si una condicion se cumple.
- Es normal que nos encontremos con [[UPDATE, INSERT, SET]]
```sql
IF |CONDICION| THEN
	---CODIGO QUE SE EJECUTA SI ESA CONDICION ES CIERTA.
END IF;
```

```sql
IF |CONDICION| THEN
	---CODIGO QUE SE EJECUTA
ELSEIF |OTRA CONDICION| THEN
	---CODIGO QUE SE EJECUTA
ELSE
	---CODIGO QUE SE EJECUTA
END IF;
```

```SQL
CASE |EXPRESION|
	WHEN |VALOR1| THEN
	---CODIGO QUE SE EJECUTA
	WHEN |VALOR2| THEN
	---CODIGO QUE SE EJECUTA
	ELSE
	---CODIGO QUE SE EJECUTA
END CASE;
```
